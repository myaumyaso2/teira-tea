# 🍵 ТЕЙРА (TEIRA) — Интернет-магазин селекционного чая

Премиальный интернет-магазин селекционного чая прямого импорта с высокогорных плантаций Юньнани, гор Уи и Тайваня. Проект разработан в соответствии с утвержденным брендбуком **TEIRA 2026 («Финальный выбор»)**, дизайн-системой **StitchMCP** и векторными ассетами из **Figma MCP**.

---

## ✨ Ключевые возможности и разделы

1. **🌿 Атмосферный Hero & Brand Cover:**
   - Утвержденная визуальная обложка (Слайд 001 брендбука), акцидентная типографика Bebas Neue и официальная метафора знака.
2. **🍵 Смысловая анатомия знака (5 элементов бренда):**
   - Разбор символики: Чашка/Пиала, Чайные террасы/Волны, Чайный лист, Парящая чайка, Солнце/Капля.
3. **📦 Фирменные упаковки и сборы (Слайды 039–041):**
   - Изумрудные и белые герметичные тубусы, крафтовые дой-паки с клапаном дегазации, подарочные гранд-боксы из дерева с сургучной печатью.
   - Интерактивный селектор граммовок (50г, 100г, 250г, 357г) с расчетом цены за грамм.
4. **🎨 Фирменная палитра PANTONE & Штампы качества (Слайды 028, 032–035):**
   - Основной изумрудный (`#035224` | PANTONE 6182 C), Свежий оливковый (`#89AA3E` | PANTONE 4212 C), Светлый песок (`#EEE1D5` | PANTONE 7506 C), Теплая охра (`#C9A456` | PANTONE 4019 C), Терракота (`#D4583D` | PANTONE 7619 C).
   - Быстрое копирование HEX-кодов в 1 клик.
5. **📱 Цифровая экосистема бренда (Слайды 023, 025, 027):**
   - Мокапы веб-витрины `teira.com/store`, мобильного приложения и PWA-знака.
6. **🎯 4-шаговый Чайный Квиз (Tea Matcher):**
   - Алгоритм подбора сортов под ритм дня, генерация персональной карты вкусов, промокод `TEIRA2026` на скидку 15% и добавление сета в корзину в 1 клик.
7. **🛍️ Cart Drawer & Быстрый чекаут:**
   - Боковая шторка с динамической шкалой бесплатной доставки СДЭК (порог 3 500 ₽) и экспресс-оформлением.
8. **💼 B2B / HoReCa:**
   - Блок для ресторанов и спешелти-кофеен с формой запроса бесплатного дегустационного набора.

## 🛠️ Стек технологий

- **Фреймворк:** Next.js 15 (React 19, App Router, TypeScript)
- **Стилизация:** Tailwind CSS (кастомная дизайн-система `teira`)
- **Анимации и эффекты:** Framer Motion, Canvas Confetti
- **Иконки:** Lucide React
- **Интеграции дизайна:** Figma MCP, StitchMCP

## 🚀 Локальный запуск

1. **Клонирование репозитория:**
```bash
git clone https://github.com/myaumyaso2/teira-tea.git
cd teira-tea
```

2. **Установка зависимостей:**
```bash
npm install
```

3. **Запуск сервера разработки:**
```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

4. **Сборка для продакшена:**
```bash
npm run build
npm start
```
